Tema clássico para o acervo histórico do Município de Boa Viagem (CE).

== Descrição ==
Design system próprio (tokens e componentes), templates para os tipos de conteúdo do plugin HBV Core (biografias, lugares, logradouros, datas e fatos, obras, instituições) e suas taxonomias de tema e período histórico, padrões de bloco para citações, leis e legendas, índice A–Z, calendário por mês e linha do tempo.

== Instalação ==
1. Envie e ative o tema.
2. Instale e ative o plugin HBV Core (tipos de conteúdo, taxonomias e campos).
3. Abra Ferramentas > Estrutura inicial HBV e crie as páginas e o menu.
4. Defina a página inicial, o logotipo e a imagem do cabeçalho no Personalizador.
5. Leia docs/GUIA-DO-TEMPLATE.md.

== Documentação ==
docs/RESUMO-DO-SITE.md, docs/DESIGN-SYSTEM.md, docs/GUIA-DO-TEMPLATE.md e docs/design-system.html.

== Privacidade ==
O tema não carrega fontes, scripts nem contadores de terceiros. Os links de compartilhamento abrem os serviços apenas quando o visitante clica.
